These slides were created by Alejandro Fontan as part of the SLAM course.

I have made every effort to acknowledge all sources from which slides, images, or videos were used. If I have made an error or omission, please let me know. This is ongoing work — corrections, improvements, and acknowledgments will continue to be added over time.

**Special acknowledgments**

**Cyrill Stachniss** — Photogrammetry and Robotics. These slides draw heavily on Cyrill Stachniss's course material. That material in turn relied on the lecture notes by Wolfgang Förstner and the book *Photogrammetric Computer Vision* by Förstner & Wrobel. Parts of the robotics content are based on *Probabilistic Robotics* by Thrun, Burgard, and Fox.

**Kaveh Fathian** — Robotic Mapping and Localization, Colorado School of Mines, Department of Computer Science. These slides draw heavily on the course material, which was itself compiled from several courses, lectures, and code repositories. Corresponding references are cited at the end of each lecture.

**Antonio Torralba, Phillip Isola, and William T. Freeman** — *Foundations of Computer Vision*. Some images are sourced from this book.

**L. Carlone, A. Kim, T. Barfoot, D. Cremers, and F. Dellaert** — *SLAM Handbook: From Localization and Mapping to Spatial Intelligence*, eds. Cambridge University Press, 2026.

**For Educators:** university lecturers are welcome to use this material freely. If you adapt it, please retain all existing acknowledgments and add an acknowledgment to Alejandro Fontan. As a personal favour, I would appreciate an email notice if you use these slides.
